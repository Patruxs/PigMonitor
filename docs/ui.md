# How the UI is built

- **Look.** The plugin SDK gives only colours (`PluginTheme`), so `client/kit/theme.ts` copies Paseo's spacing, font sizes, icon sizes, radii and control geometry from Paseo's app source (`packages/app/src`: `styles/theme.ts`, `styles/settings.ts`, `screens/settings/providers-section.tsx`, `components/ui/control-geometry.ts` and `components/ui/segmented-control.tsx`, read on 2026-09-28, when the plugin SDK was 0.9.1). What is shown follows piggery top. The finish follows Paseo's Settings → Providers screen: small muted labels, and rows split by rules in the border colour. `ROW_MIN` is Paseo's `FIELD_CONTROL_HEIGHT`. Colours always come from the theme prop, never from `theme.ts`.
- **Pressable rows** (`client/kit/press.tsx`) move one surface shade on hover and one more on press, instantly, like the rows of Paseo's progress plugin. There is no animation, so reduced motion has nothing to turn off.
- **Lists** (`client/kit/rows.tsx`) run full width with a rule above each row. Inside a card (`bare`) the first and last rules are left to the card.
- **A folding line** (`client/piggery/disclosure.tsx`) takes either `aside` or `onBody`, never both. `aside` is a button at the right edge, outside the pressable part. With `onBody`, only the chevron folds, a press on the rest of the line calls `onBody`, and the line keeps the room the aside would take, so its columns stay under the other lines' columns.
- **The detail dialog** (`client/dialog.tsx`) changes its content in place, and Back returns to the step before. The host gives each dialog its own backdrop, so a second dialog would darken the screen while the first fades.
- **The Graph** (`graphOf` in `client/surface.tsx`) hangs each visible row from the nearest visible row above it in the view's tree, or from the team when none is shown. So no card is lost when its lead is hidden or gone.
- **Polling** (`client/poll.ts`): `ps --view` reads the workers' logs, so the view is asked for every `BUSY_MS` (5 s) while something works or waits, and every `QUIET_MS` (30 s) otherwise. A hidden page skips its polls and asks at once when it is shown again. `Loaded.at` is when the value was read, in ms; it is null before the first read.
